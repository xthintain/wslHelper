# Feature Specification: WSL截图工具

**Feature Branch**: `001-wsl-screenshot-tool`
**Created**: 2025-11-12
**Status**: Draft
**Input**: WSL截图工具 - Windows平台下的截图工具，自动将Windows路径转换为WSL路径格式并保存到剪贴板

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 快速截图并获取WSL路径 (Priority: P1)

用户在使用WSL环境开发时，需要截取Windows屏幕上的内容并快速获得可在WSL终端中直接使用的文件路径。

**Why this priority**: 这是工具的核心价值主张，解决了WSL用户最常见的痛点 - Windows和WSL路径格式不兼容导致的工作流中断。

**Independent Test**: 用户按下快捷键，选择截图区域，释放鼠标后，剪贴板中包含WSL格式的路径（如 `/mnt/e/tmp/screenshot_20251112_143020.jpg`），该路径可在WSL终端中直接使用。

**Acceptance Scenarios**:

1. **Given** 用户在Windows系统中工作，**When** 按下截图快捷键（默认Ctrl+Alt+A），**Then** 系统显示全屏半透明遮罩，允许用户拖拽选择截图区域
2. **Given** 用户已选择截图区域，**When** 释放鼠标左键，**Then** 截图保存到默认临时目录（E:\tmp\screenshots\），WSL路径（/mnt/e/tmp/screenshots/screenshot_YYYYMMDD_HHMMSS.jpg）自动复制到剪贴板，显示成功通知
3. **Given** 用户已获得WSL路径，**When** 在WSL终端粘贴该路径，**Then** 路径指向正确的截图文件
4. **Given** 用户按ESC键，**When** 在选择区域过程中，**Then** 取消截图操作，不保存任何文件

---

### User Story 2 - 管理和配置截图设置 (Priority: P2)

用户希望自定义截图工具的行为，包括保存路径、快捷键、图片格式等，以适应个人工作流。

**Why this priority**: 提供灵活性和用户控制权，但不是核心功能。默认配置已能满足基本使用。

**Independent Test**: 用户通过托盘图标打开设置界面，修改保存路径为D:\screenshots，保存后下次截图文件保存到新路径，剪贴板路径也相应更新为 /mnt/d/screenshots/...

**Acceptance Scenarios**:

1. **Given** 用户右键点击系统托盘图标，**When** 选择"设置"菜单项，**Then** 打开设置界面显示当前配置
2. **Given** 用户在设置界面中修改快捷键，**When** 点击保存，**Then** 新快捷键立即生效，旧快捷键失效
3. **Given** 用户修改默认保存路径为自定义目录，**When** 保存设置，**Then** 后续截图保存到新路径，且自动创建目录（如不存在）
4. **Given** 用户修改图片格式为PNG，**When** 下次截图，**Then** 保存的文件为PNG格式，路径扩展名正确

---

### User Story 3 - 开机自动启动并后台运行 (Priority: P3)

用户希望工具在系统启动时自动运行并驻留后台，随时可用而无需手动启动。

**Why this priority**: 这是便利性功能，提升用户体验但不影响核心截图功能。用户可以手动启动使用。

**Independent Test**: 用户在设置中启用"开机自启动"，重启Windows后，工具自动启动并显示托盘图标，快捷键立即可用。

**Acceptance Scenarios**:

1. **Given** 用户在设置中启用"开机自启动"，**When** Windows系统重启，**Then** 工具自动启动，托盘图标出现，快捷键可用
2. **Given** 工具在后台运行，**When** 用户未进行截图操作，**Then** CPU占用低于1%，内存占用低于50MB
3. **Given** 工具需要管理员权限，**When** 程序启动，**Then** 显示UAC提示请求管理员权限，说明需要权限以截取所有窗口
4. **Given** 用户禁用"开机自启动"，**When** Windows系统重启，**Then** 工具不自动启动

---

### Edge Cases

- **多显示器环境**: 用户在多显示器环境下截图时，如何确定在哪个显示器上截图？系统应允许用户在任意显示器上拖拽选择区域。
- **高DPI显示器**: 在125%、150%、200%缩放比例下，截图区域坐标和实际像素坐标可能不一致，需正确处理DPI缩放。
- **路径包含特殊字符**: 如果保存路径包含空格、中文或特殊字符（如 "E:\我的 文件夹\截图.jpg"），转换后的WSL路径应正确处理（/mnt/e/我的 文件夹/截图.jpg）。
- **磁盘空间不足**: 当临时目录所在磁盘空间不足时，截图保存失败，应显示明确错误提示并建议用户清理文件或更改保存路径。
- **权限不足**: 在非管理员模式下，部分需要管理员权限的窗口无法截取，应提示用户以管理员身份运行。
- **快捷键冲突**: 用户设置的快捷键与其他软件冲突时，快捷键可能不响应，应在设置界面提供冲突检测或建议。
- **临时文件累积**: 长期使用后，临时目录可能累积大量截图文件，应提供可选的自动清理功能（按时间或数量）。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统必须支持全局快捷键触发截图功能（默认Ctrl+Alt+A，用户可自定义）
- **FR-002**: 系统必须允许用户通过鼠标拖拽选择任意矩形区域进行截图
- **FR-003**: 系统必须在用户选择区域时显示半透明遮罩和选区边框，提供视觉反馈
- **FR-004**: 系统必须支持ESC键取消截图操作
- **FR-005**: 系统必须将截图自动保存到配置的临时目录（默认 E:\tmp\screenshots\）
- **FR-006**: 系统必须为截图文件生成唯一的时间戳文件名（格式：screenshot_YYYYMMDD_HHMMSS.jpg）
- **FR-007**: 系统必须自动创建保存目录（如不存在）
- **FR-008**: 系统必须将Windows路径转换为WSL路径格式（盘符转小写，如 E:\ → /mnt/e/，反斜杠转正斜杠）
- **FR-009**: 系统必须自动将转换后的WSL路径复制到Windows剪贴板
- **FR-010**: 系统必须在截图成功后显示Windows Toast通知，包含WSL路径
- **FR-011**: 系统必须提供系统托盘图标，显示运行状态
- **FR-012**: 系统必须通过托盘右键菜单提供设置入口
- **FR-013**: 设置界面必须允许用户自定义快捷键、保存路径、图片格式（JPG/PNG）、图片质量
- **FR-014**: 系统必须支持开机自启动功能（可通过设置启用/禁用）
- **FR-015**: 系统必须在启动时请求管理员权限（通过UAC提示）
- **FR-016**: 系统必须支持多显示器环境，允许在任意显示器上截图
- **FR-017**: 系统必须正确处理高DPI显示器（125%、150%、200%缩放）
- **FR-018**: 系统必须记录关键操作日志（启动、截图、错误）到本地日志文件
- **FR-019**: 系统必须在发生错误时显示友好的错误提示（如权限不足、磁盘空间不足）
- **FR-020**: 系统必须提供可选的临时文件清理功能（按时间或数量，默认禁用）

### Key Entities

- **截图 (Screenshot)**: 表示一次截图操作的结果
  - 属性: 文件路径（Windows格式）、WSL路径、文件名、创建时间、图片格式、文件大小

- **配置 (Configuration)**: 存储用户的偏好设置
  - 属性: 快捷键、保存目录、图片格式、图片质量、开机自启动标志、显示通知标志、自动清理设置

- **操作日志 (Log Entry)**: 记录系统操作和错误
  - 属性: 时间戳、日志级别（DEBUG/INFO/WARNING/ERROR）、消息内容

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 用户在按下快捷键后，截图遮罩必须在200毫秒内显示
- **SC-002**: 用户释放鼠标后，截图处理（保存+路径转换+剪贴板复制）必须在500毫秒内完成（1080p分辨率）
- **SC-003**: 工具在后台运行时，CPU占用率必须低于1%（空闲状态）
- **SC-004**: 工具在后台运行时，内存占用必须低于50MB
- **SC-005**: 工具启动时间必须低于3秒（从进程启动到快捷键可用）
- **SC-006**: 路径转换必须100%准确，所有常见盘符（C-Z）和路径格式都能正确转换
- **SC-007**: 用户通过WSL终端使用剪贴板中的路径时，90%以上情况下无需手动修改即可直接使用
- **SC-008**: 系统必须支持至少Windows 10和Windows 11操作系统
- **SC-009**: 工具必须能够处理至少3个显示器的多显示器环境
- **SC-010**: 在高DPI显示器（200%缩放）下，截图区域选择的像素级精度误差必须小于2像素
- **SC-011**: 用户修改配置后，新配置必须在下次操作时立即生效（无需重启）
- **SC-012**: 系统出现错误时，95%以上的错误必须有清晰的用户友好提示信息
- **SC-013**: 开机自启动功能的成功率必须高于95%（在支持的Windows版本上）

## Assumptions

- 用户已安装WSL（Windows Subsystem for Linux）并理解WSL路径格式
- 用户使用的是Windows 10或Windows 11操作系统（x64架构）
- 用户具备基本的计算机操作能力（理解快捷键、系统托盘等概念）
- 默认保存路径 E:\tmp\screenshots\ 中的E盘存在且有写入权限（如不存在，工具将在首次运行时引导用户设置）
- Python 3.9+运行环境可用（或工具以独立可执行文件形式发布，无需用户安装Python）
- 用户愿意授予管理员权限以截取所有窗口（工具在启动时会明确说明原因）

## Constraints

- 工具仅支持Windows平台（未来版本可能扩展到Linux和macOS）
- 截图功能依赖Windows图形API，不支持远程桌面环境下的远程屏幕截图
- 管理员权限是可选的，但在非管理员模式下无法截取需要管理员权限的窗口
- 路径转换仅支持WSL 1和WSL 2的标准挂载点（/mnt/盘符）格式，不支持自定义挂载点
- 图片格式仅支持JPG和PNG，不支持其他格式（如BMP、WEBP等，可在未来版本添加）
- 工具不提供截图编辑功能（如标注、裁剪等，可在未来版本添加）
- 工具不收集任何用户数据，所有配置和日志仅存储在本地

## Dependencies

- 用户系统必须安装Windows 10或更高版本
- 用户系统必须安装WSL（用于验证路径转换的正确性）
- 工具依赖以下Python库（如以独立可执行文件发布则无需用户安装）：
  - PyQt5（GUI框架）
  - Pillow（图像处理）
  - mss（截图库）
  - pywin32（Windows API调用）
  - pynput（快捷键监听）
- 工具需要访问Windows注册表以实现开机自启动功能
- 工具需要访问剪贴板API以实现路径复制功能
